TWITTER SENTIMENT ANALYSIS
===========================

Project Type:
End-to-End Classical NLP + Machine Learning + Streamlit Deployment

Objective:
Build an end-to-end Twitter/X sentiment analysis system using the Twitter US Airline Sentiment dataset. The project will cover data acquisition, exploratory data analysis, text preprocessing, feature engineering, classical machine learning model development, evaluation, error analysis, model serialization, and Streamlit deployment.

IMPORTANT SCOPE DECISION
------------------------
This project will NOT use Transformer NLP, RoBERTa, PyTorch, or TensorFlow.

Models:
1. VADER

============================================================
6. PHASE 2 - NLP PREPROCESSING
============================================================

Important:
Use separate preprocessing strategies for VADER and TF-IDF models.

VADER:
Minimal cleaning should be used because punctuation, capitalization, emojis, and other sentiment signals can be useful.

Classical ML:
Use cleaning, tokenization, stopword handling, and lemmatization before TF-IDF.

Text cleaning requirements:

- Convert text to lowercase
- Remove URLs
- Handle @mentions
- Handle RT
- Preserve useful hashtags
- Decide how emojis are handled
- Remove unnecessary whitespace
- Avoid destroying sentiment-bearing words
- Avoid excessive normalization

Example:

import re

def clean_text(text):

    text = text.lower()

    text = re.sub(
        r"http\S+|www\S+",
        "",
        text
    )

    text = re.sub(
        r"@\w+",
        "",
        text
    )

    text = re.sub(
        r"\brt\b",
        "",
        text
    )

    text = re.sub(
        r"\s+",
        " ",
        text
    )

    return text.strip()

============================================================
11. PHASE 3 - VADER BASELINE
============================================================

Purpose:
Create a rule-based baseline before supervised machine learning.

Example:

from nltk.sentiment import SentimentIntensityAnalyzer

sia = SentimentIntensityAnalyzer()

def vader_sentiment(text):

    score = sia.polarity_scores(text)["compound"]

    if score >= 0.05:
        return "positive"

    elif score <= -0.05:
        return "negative"

    return "neutral"

Apply:

vader_predictions = X_test.apply(
    vader_sentiment
)

Evaluate VADER using the same test set.

tfidf = TfidfVectorizer(

    sublinear_tf=True
)

Important:
TF-IDF must be fitted only on training data.

Use a Scikit-Learn Pipeline to reduce leakage risk.

accuracy = accuracy_score(

    y_test,

Primary metric:
Macro F1

Reason:
The dataset is imbalanced, so macro F1 gives equal importance to each sentiment class.

22. STREAMLIT BASIC APPLICATION
============================================================

Example app.py:

import streamlit as st
import joblib

st.set_page_config(
    page_title="Twitter Sentiment Analyzer",
    page_icon="🐦"
)

st.title("Twitter Sentiment Analyzer")

model = joblib.load(
    "models/sentiment_model.joblib"
)

text = st.text_area(
    "Enter a tweet:"
)

if st.button("Analyze Sentiment"):

    if not text.strip():

        st.warning(
            "Please enter a tweet."
        )

    else:

        prediction = model.predict(
            [text]
        )[0]

        st.success(
            f"Predicted Sentiment: {prediction}"
        )
